                                  <h1>Descrição do Projeto</h1>
<br>
  <p>O projeto é um sistema de reservar quadras de futebol! Onde aqui existe pastas iniciais:</p>
<br>
<p>=> Controllers: A pasta que vai acessar o controle do sistema, é lá que vai receber as requisições, validar dados e chamar o Service;</p>
<br>
<p>>=> Models: Vai representar entidade, através de objetos de reservas com classes;</p>
<br>
<p>=> Routes: Vai receber rotas do site;</p>
<br>
<p> Database: Vai conectar as rotas do banco de dados através do .env relacionado a conexão;</p>
<br>
<p>=> Services: Vai operar o banco de dados</p>
<br>
<p>O projeto também terá o frontend, que o frontend vai ser relacionado ao backend, com o banco de dados, APIs e rotas!</p> 
<br>
<p>Se você quiser analisar mais profundamente o projeto, segue a instrução a seguinte:</p>
<br>
<p>- Instala o projeto do GitHub;</p>
<br>
<p>- Dentro do projeto, vá para o terminal e instale **npm install**;</p>
<br>
<p>- Para rodar o projeto, digite **node server.js**</p>
