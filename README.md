Descrição do Projeto

O projeto é um sistema de reservar quadras de futebol! Onde aqui existe pastas iniciais:


=> Controllers: A pasta que vai acessar o controle do sistema, é lá que vai receber as requisições, validar dados e chamar o Service;


>=> Models: Vai representar entidade, através de objetos de reservas com classes;


=> Routes: Vai receber rotas do site;


Database: Vai conectar as rotas do banco de dados através do .env relacionado a conexão;


=> Services: Vai operar o banco de dados


O projeto também terá o frontend, que o frontend vai ser relacionado ao backend, com o banco de dados, APIs e rotas!


Se você quiser analisar mais profundamente o projeto, segue a instrução a seguinte:


- Instala o projeto do GitHub;


- Dentro do projeto, vá para o terminal e instale **npm install**;


- Para rodar o projeto, digite **node server.js**
